## 👨‍💻 About Me

I'm **Atif Asif**, a **Senior Full-Stack Developer** from Pakistan with **4+ years** of experience building production-grade web and mobile applications. I work across the whole product: a polished mobile or web interface, a clean and secure API behind it, and a reliable cloud deployment under it.

My daily stack is **React Native, Next.js, Node.js and TypeScript**, backed by MongoDB and deployed on AWS and DigitalOcean. I care about performance, readable code and interfaces that feel good to use, and I like turning vague product ideas into shipped features.

Since 2022 I've been working full time at **Enigmatix (Pvt) Ltd**, and I also take on **freelance projects** for clients worldwide. More recently I've been adding **AI features (Claude / LLM APIs)** to real products, such as assistants, content tools and workflow automation.

> 💡 I'm happy to take on new projects. If you need an app built, an existing product improved, or an AI feature added, get in touch.
